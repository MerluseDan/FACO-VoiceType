# Support

For installation or runtime trouble:

1. Run the canonical `diagnose.sh` script.
2. Check `~/Desktop/Logs/FACO VoiceType/`.
3. Search existing GitHub issues.
4. Open a bug report with the requested environment and diagnostic details.

Remove or redact usernames, device serials, mount details, recorded audio, credentials, and unrelated personal data before posting logs publicly.

General usage questions and proposed improvements can use GitHub Discussions when enabled or a feature request otherwise.
